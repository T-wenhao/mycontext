# Triage labels

| Role            | Label             |
| --------------- | ----------------- |
| 待评估          | `needs-triage`    |
| 等待补充信息    | `needs-info`      |
| 可由 Agent 实施 | `ready-for-agent` |
| 需要人工处理    | `ready-for-human` |
| 不实施          | `wontfix`         |
